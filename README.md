### 🚀 Projeto em destaque: Centro de Comando

Um **painel pessoal privado** que reúne tudo o que eu construo e penso: projetos, ideias, notas e documentos, ligados num **mapa 3D** que se **atualiza sozinho** todos os dias a partir do Gmail, Google Drive, Agenda e Notion.

**Tecnologias:** Python · JavaScript · three.js (3D) · Node.js · Vercel (serverless) · Supabase (PostgreSQL) · Web Push · IA
